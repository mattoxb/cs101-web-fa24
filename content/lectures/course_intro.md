## Topic

"Why do I need to know Python?"  Today we will talk about how knowing a little bit about programming can enhance
your skill in whatever major you have chosen.  We will get started writing our first Python program online
(no need to install anything if you don't want to!) and show you where to find all the things you will need to
succeed in this course.

## Learning Objectives

- Meet your instructor and your TAs.
- Find the syllabus and getting started guide on the main web page.
- Open the lecture content on PrairieLearn and write some simple Python programs.
- Start the post-class activity and get your first points.
